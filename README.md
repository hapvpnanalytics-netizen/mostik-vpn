# Мостик VPN · Mostik VPN

**VPN для Windows и Android с режимом раздельного доступа.**

Одним приложениям нужен VPN, другим — обычное подключение. Мостик разделяет трафик по правилам: выбранные сервисы работают через VPN, а остальные могут подключаться напрямую. Это помогает реже включать и выключать VPN при переходе между задачами.

## Режим раздельного доступа

Раздельный доступ, или *split tunneling*, позволяет одновременно использовать два маршрута:

- **Через VPN** — для сервисов и программ, которым нужно VPN-подключение.
- **Напрямую** — для трафика, который должен идти через обычное соединение вашего провайдера.

Прямой трафик не проходит через VPN-сервер. Какой маршрут получит конкретная программа или сервис, определяют правила и выбранные настройки.

### Что это даёт на практике

- **Меньше ручных переключений.** Можно пользоваться сервисом через VPN и переходить к приложению с прямым подключением, не отключая весь VPN.
- **Обычный маршрут там, где он нужен.** Локальные сервисы можно оставить на прямом соединении, без дополнительного пути через VPN-сервер.
- **Настройка под свои задачи.** В Windows доступны правила отдельных программ. В Android можно начать с готовых списков и выбрать, куда направлять остальной трафик.

Например, на Windows можно отправить один браузер через VPN, а другой браузер или отдельную программу — напрямую. Для этого задаются правила их исполняемых файлов. Результат зависит от выбранных правил и работы сервисов в вашей сети.

### Windows и Android: как настраивается режим

| Возможность | Windows | Android |
| --- | --- | --- |
| Основа разделения | Режим выбранных сервисов и редактор правил | Готовые списки «Через VPN» и «Напрямую (без VPN)» |
| Свои правила для программ | Можно указать файл `.exe` и выбрать VPN или прямой маршрут | Готовые списки не являются редактором отдельных приложений |
| Настройка остального трафика | Маршруты определяются правилами выбранного режима | Переключатель «Все остальные»: «Через VPN» или «Напрямую» |

#### Windows: правило для конкретной программы

1. Откройте **Правила → Правила Mostik VPN**.
2. В поле **Тип** выберите **Приложение**.
3. Нажмите **Выбрать .exe** и укажите исполняемый файл программы.
4. В поле **Куда** выберите **Mostik VPN** или **Direct**.
5. Нажмите **Добавить**, затем **Сохранить**. Переподключитесь и проверьте программу.

#### Android: маршрут для остальных приложений

1. На главном экране посмотрите списки **Через VPN** и **Напрямую (без VPN)**.
2. В блоке **Все остальные** выберите нужный маршрут. По умолчанию для остальных выбран вариант **Через VPN**.
3. Если выбрано **Напрямую**, трафик вне готовых списков будет идти без VPN. Сами списки сохраняют свои правила.
4. Настройка сохраняется автоматически. При включённом VPN дождитесь переподключения и проверьте нужные сервисы.

## Первое подключение

1. Скачайте и установите приложение для своего устройства.
2. Введите email и подтвердите вход кодом из письма.
3. Нажмите кнопку подключения.
4. Настройте раздельный доступ и проверьте привычные приложения.

Новым пользователям доступен пробный период **72 часа с первого нажатия кнопки подключения**. Он позволяет проверить работу Мостика в своей сети; банковская карта не нужна. После пробного периода для дальнейшего использования требуется оплаченный доступ. Автоматических списаний нет, повторная установка не выдаёт новый пробный период.

## English

Mostik VPN provides **split tunneling for Windows and Android**: selected traffic uses the VPN while other traffic can connect directly.

- **Windows:** create rules for individual application executables and choose a VPN or direct route.
- **Android:** use predefined routing lists and choose the route for traffic outside those lists with the “All others” setting.
- **Getting started:** download an installer above and sign in using an email code. No manual VPN profile import is needed.

This repository distributes installers and release documentation. A 72-hour trial is available to new users; continued use requires paid access.
