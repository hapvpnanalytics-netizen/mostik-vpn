## Первое подключение

1. Скачайте и установите приложение для своего устройства.
2. Войдите в Мостик по email и подтвердите код из письма.
3. Нажмите кнопку подключения в приложении, чтобы активировать пробный период.
4. Проверьте работу нужных сервисов в своей сети и настройте разделение трафика.

Пробный период длится **72 часа с момента активации в приложении**. Он доступен новым пользователям и не выдаётся повторно при переустановке. После его окончания можно выбрать срок доступа в приложении или кабинете. Автоматических списаний нет.

Если Мостик уже установлен, используйте email существующего аккаунта: действующий срок доступа сохраняется.

## Разделение трафика

- **Windows:** задавайте маршрут для отдельных программ — через VPN или напрямую.
- **Android:** используйте готовые списки и настройку «Все остальные» для приложений вне списков.
